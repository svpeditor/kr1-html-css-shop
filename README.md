# Клац - учебный интернет-магазин механических клавиатур

## Контрольная работа №1

Тема: «HTML и CSS: разработка многостраничного сайта».

Сделан многостраничный HTML/CSS-сайт учебного интернет-магазина механических клавиатур "Клац". Проект выполняется в рамках дисциплины «Фронтенд и бэкенд разработка», без CSS-фреймворков, JavaScript используется только для модального окна и формы.

## Ссылка на опубликованный проект

GitHub Pages: https://svpeditor.github.io/kr1-html-css-shop/

## Как посмотреть проект

Открыть ссылку GitHub Pages выше. Или скачать репозиторий и открыть index.html в браузере, сервер не нужен.

## Страницы

- index.html - главная: hero-блок, преимущества, популярные товары, отзывы, модальное окно быстрого заказа
- catalog.html - каталог: категории с якорными ссылками, статический блок фильтров, 10 карточек товаров
- product.html - карточка товара Клац 60: фото, описание, цена, таблицы характеристик и комплектаций, похожие товары
- order.html - оформление заявки: форма с проверкой полей
- contacts.html - контакты, режим работы, частые вопросы
- delivery.html - доставка и оплата (дополнительная страница)

Страница product.html сделана на примере одного товара, ссылки "Подробнее" из всех карточек ведут на неё.

## Структура проекта

- index.html, catalog.html, product.html, order.html, contacts.html, delivery.html - страницы сайта
- css/style.css - общий файл стилей
- js/main.js - открытие модального окна и обработка формы
- images/ - фотографии товаров
- screenshots/ - скриншоты к практической работе 1
- .gitignore - список файлов, исключённых из Git
- README.md - описание проекта

## Используемые технологии

- HTML
- CSS (переменные, Flexbox, Grid)

- Git
- GitHub Pages

## Что есть в проекте по требованиям КР №1

- семантическая разметка: header, nav, main, section, article, aside, footer
- единое меню на всех страницах и якорные ссылки (index.html#advantages, index.html#popular, index.html#contacts, разделы каталога)
- карточки товаров выстроены через CSS Grid
- таблицы характеристик, комплектаций и доставки с caption, thead, tbody, th, td
- форма заявки на order.html и в модальном окне на главной (dialog)
- CSS-переменные в :root, состояния :hover, :focus-visible, :disabled
- Flexbox в шапке, меню, кнопках и подвале, Grid в сетке карточек, каталоге с фильтрами, странице товара и подвале
- имена классов по БЭМ: site-header__logo, site-nav__link--active, product-card__title, product-card--discount, order-form__input
- позиционирование: sticky у шапки и фильтров, relative у карточки, absolute у бейджа, fixed у кнопки "Наверх", z-index у шапки и кнопки

## Самостоятельные доработки

- своё оформление магазина: тёмная шапка и подвал, оранжевый акцентный цвет, шрифт Rubik, фотографии товаров
- дополнительная страница доставки и оплаты с таблицей
- на главной добавлены отзывы покупателей и блок консультации
- бейджи "Хит", "Новинка", "Скидка", старая цена у товаров со скидкой, товар "нет в наличии" с отключённой кнопкой
- хлебные крошки на внутренних страницах, меню разделов на странице товара, категории каталога
- кнопка "Заказать" в каталоге открывает заявку уже с выбранным товаром (параметр product в адресе)
- в модальном окне видно, какой товар выбран, после отправки появляется сообщение
- таблица сравнения комплектаций на странице товара
- частые вопросы на странице контактов через details и summary
- видимый фокус у всех ссылок, кнопок и полей, у каждого поля есть label

## Постановка контрольной работы №1

Тема контрольной работы №1: «HTML и CSS: разработка многостраничного сайта».

В рамках контрольной работы необходимо разработать многостраничный HTML/CSS-сайт интернет-магазина или каталога услуг.

Проект должен включать:

- главную страницу
- страницу каталога
- страницу карточки товара или услуги
- страницу оформления заявки
- страницу контактов
- семантическую HTML-разметку
- внешний CSS-файл
- базовую навигацию
- оформление основных блоков страницы

- Контрольная работа 1: сайт расширен до шести страниц, добавлены каталог, карточка товара, заявка, контакты и доставка, Flex/Grid, БЭМ и позиционирование.

## Реализованные элементы интерфейса

- кнопки заказа в карточках товаров
- модальное окно с формой заявки

- базовая HTML-валидация
- базовая JS-обработка формы
- сообщение об успешной отправке

В проекте используются:

- CSS-переменные в :root
- единая шкала отступов
- переменные для цветов и скруглений
- состояния :hover, :focus-visible, :disabled
